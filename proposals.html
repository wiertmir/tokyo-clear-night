Trait names: #8fb3ad italic (revised)

Proposal for "interface": { "foreground": "#8fb3ad", "italic": true } (rust-analyzer's token for traits). Shown on Tokyo Clear Night #1a1b26.

Why it reads as vague

A desaturated sea-mist grey-green, hazy rather than crisp. Concrete types stay saturated; abstractions get the muted, in-between color. The first proposal, a heather purple, was too close to the italic purple of async, mut and pub (#9d7cd8); this one keeps clear of every purple.

Consuming methods: bold

Methods that take self by value (rust-analyzer's consuming modifier) move their receiver. Rule: "method.consuming": { "foreground": "#7aa2f7", "bold": true }. Same blue, heavier weight. iter only borrows, so it stays regular.

Macro calls: mint

Macros are functions that write code at compile time, but they share the function blue #7aa2f7, so println! looks like any call. Orchid was too close to the purple of async, and amber too close to the boolean orange (hues 45° vs 22°, with the parameter tan at 36° in between). The warm band is crowded; the free gap is hue 150°, between string green (89°) and teal (171°). Proposal: mint #55e7a3 for the name and the !, regular weight. Rules: "macro" and "macro.defaultLibrary".

Now
let items = vec![3, 1, 2];
println!("{}", total(&items));

Greys and silvers for macro names and their !. Distance is CIELAB units to the nearest existing color; below ~19 a color is easily confused.
